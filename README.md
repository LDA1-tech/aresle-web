# ARESLE SRL — sitio web

Sitio de ARESLE SRL (construcción modular). Vite + React + TypeScript + shadcn/ui + Tailwind CSS.

## Desarrollo local

Requiere Node.js y npm.

```sh
npm i
npm run dev
```

## Build de producción

```sh
npm run build
```

## Deploy

El deploy a producción es automático: cada push a `main` en [github.com/LDA1-tech/aresle-web](https://github.com/LDA1-tech/aresle-web) dispara un build en Vercel.

Producción: https://aresle-web.vercel.app
